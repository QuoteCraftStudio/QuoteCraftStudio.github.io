Idea Hub Mobile

Version 1.0.1 · October 2026

What it does

A free, compact mobile view for the same Idea Hub community. Browse discussions by category, search, create posts, read and write comments, review your own posts and report content. It has compact/expanded and supported browser full-screen views.

Install

Open Idea Hub Mobile in your phone’s Chrome browser and choose Add to Home screen or Install app from the browser menu. Internet access is needed for discussions, posting and sign-in. This is a web app, not an Android APK.

Privacy and security

The app uses the existing secure Cloudflare and Firebase services. It does not save passwords, sign-in tokens, private responses or personal profile data to permanent browser storage. Submitted public text is screened for safety. Posts cleared by automated screening appear publicly; flagged posts remain private for moderator review.

Read our full Privacy Policy, Terms of Use, Community Guidelines and Reporting & Safety.

Release, HTTPS and signature

The live application is served securely over HTTPS from GitHub Pages. The separate QuoteCraftStudio.ca site uses its own host and HTTPS certificate. Our build workflow produces a checksum and requests a GitHub/Sigstore build attestation for the downloadable source package when the release job succeeds. These do not constitute an Android signing certificate or a guarantee of fault-free software.
