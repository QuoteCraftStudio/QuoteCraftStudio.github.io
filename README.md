## Overview

This repository contains the **GitHub Pages source for Idea Hub**, a QuoteCraft Studio community project organized around ideas, creative projects, technology, and questions.

**[Visit Idea Hub](https://quotecraftstudio.github.io/)** · **[Visit QuoteCraft Studio](https://quotecraftstudio.ca)**

## Explore the project

- **Ideas & inventions** — space for practical ideas and creative thinking.
- **Projects & DIY** — discuss hands-on projects and approaches.
- **Technology & apps** — talk about software and digital tools.
- **Questions & help** — exchange questions and useful answers.

## Deployment and release information

The site is served through GitHub Pages; **there is currently no GitHub Release package** associated with this repository. Website changes and app downloads are separate processes.
